# Design Code — English.grammar

Тёмный, «кодовый» стиль. Моноширинный шрифт для форм глагола, цвет = аспект.
Всё, что ниже, уже реализовано в `styles/design.css` и показано в `index.html`.

## Цвета

| Токен | Hex | Смысл |
|---|---|---|
| `--bg` | `#0a0b10` | фон страницы (почти чёрный с синевой) |
| `--bg-2` | `#14161f` | карточки |
| `--text` | `#f3f4f8` | основной текст |
| `--text-dim` | `#7d8294` | подписи, переводы |
| `--simple` | `#5f8bff` 🔵 | **Simple** — факт / привычка |
| `--continuous` | `#35d488` 🟢 | **Continuous** — процесс, «сейчас» |
| `--perfect` | `#f5a63b` 🟠 | **Perfect** — результат |
| `--perfcont` | `#ac8cf6` 🟣 | **Perfect Continuous** — процесс + результат |
| `--now` | `#ffd233` 🟡 | маркер «сейчас» на таймлайнах |

Правило: цвет аспекта держится **через весь сайт** — коннекторы, формы глагола,
таймлайны, бейджи, левая полоса карточек.

## Шрифты

- **Sans** (заголовки, RU-тексты): SF Pro Display / Inter — жирный, минусовый трекинг.
- **Mono** (формы глагола, теги, числа): SF Mono / JetBrains Mono. Это «фишка» стиля.

## Компоненты (готовы)

1. **Tense tree** — мини-mind-map. Слева нода времени (`present/past/future`),
   SVG-коннекторы четырёх цветов, справа 4 аспекта. Ключевое слово формы
   подсвечено цветом аспекта (`I have `**`done`**).
2. **Timeline** — ось `PAST → FUTURE`, пунктирный маркер `NOW`, ромбы-события,
   подпись-маркер (`every morning`).
3. **Example card** — предложение моно + подчёркнутый глагол + курсивный RU-перевод.
4. **Time scale** — «лестница» `+3…−3` (yesterday/today/tomorrow) с RU справа.
5. **Pill / badge** — `SIMPLE · 1/13` в рамке цвета аспекта.
6. **Topic cards** — плитки оглавления с цветной левой полосой по аспекту.
7. **Progress dots** — прогресс урока.

## Принципы наполнения

- Каждое правило = одна короткая мысль + пример EN + перевод RU.
- Сначала логика/картинка (таймлайн, ось), потом текст.
- Минимум терминов, максимум «когда так говорят».
- Один экран = одна идея (как в сторис-карточках).
