# Дизайн-система langlab

Моноширинный, «кодовый» стиль. Цвет = смысл: у каждой категории курса свой цвет,
и он держится через весь экран — бейдж, формы, таймлайн, лента прогресса, кнопки.
Всё, что описано ниже, живёт в `ui/*.css` и настраивается токенами.

## Темы

Светлая и тёмная равноправны. Каждый токен объявлен один раз через `light-dark()`
в `tokens.css`, переключение — смена `color-scheme` на `<html>`:

- нет `data-theme` → как в системе (по умолчанию);
- `data-theme="light"` / `"dark"` → явный выбор пользователя, хранится в `prefs.theme`.

Кнопка в шапке гоняет по кругу: система → светлая → тёмная.

## Цвет

| Токен | Смысл |
|---|---|
| `--bg` · `--bg-1` · `--bg-2` · `--bg-3` | фон страницы → панель → карточка → подложка |
| `--text` · `--text-soft` · `--text-dim` · `--text-faint` | четыре ступени контраста |
| `--hairline` · `--hairline-2` | границы |
| `--c-blue` · `--c-green` · `--c-orange` · `--c-purple` | палитра категорий курса |
| `--c-now` | маркер «сейчас» на таймлайне |
| `--good` · `--bad` | верно / мимо |
| `--accent` · `--on-accent` | цвет текущего экрана и текст поверх заливки им |

**Правило:** компоненты в `ui/` красятся только через `--accent`. Какой это цвет —
решает курс (`content/<code>/index.js`, поле `categories`), движок ставит его инлайном
на корень экрана. Поэтому классов вида `.a-simple` в UI нет: они бы привязали
дизайн-систему к английским временам.

## Шрифты

- **Sans** (заголовки, RU-тексты): SF Pro Display / Inter — жирный, минусовый трекинг.
- **Mono** (формы глагола, теги, числа): SF Mono / JetBrains Mono. Это «фишка» стиля.

## Mobile-first

Базовые правила описывают телефон, медиа-запросы идут только вверх
(`560px` — сетки в две колонки, `720px` — крупная типографика и обычные отступы,
`900px` — карта времён с SVG-коннекторами).

- минимальная площадь тапа — `--tap` (44px);
- кнопки урока/теста липнут к низу экрана, с учётом `safe-area-inset`;
- листание шагов урока — свайпом; клавиатурные подсказки показываются только там,
  где есть курсор (`hover: hover`);
- широкое (таймлайны, формулы) не растягивает страницу, а прокручивается внутри себя;
- `prefers-reduced-motion` выключает анимации.

## Компоненты

1. **Timeline** — ось `PAST → FUTURE`, пунктирный маркер `NOW`, фигуры-«почерки»
   (ромбы, волна, стрелка, горка, дуга), рисуются анимацией.
2. **Explorer** — интерактивная карта: узел времени, SVG-коннекторы, строки категорий.
3. **Rail** — тонкая цветная лента всех уроков курса: пройдено / текущий.
4. **Card** — плитка темы с цветной полосой слева.
5. **Pill** — `CONTINUOUS · 6/19` в рамке цвета категории.
6. **Rev-card** — пример: тап открывает перевод (или ответ в режиме «скажи сам»).
7. **Quiz** — семь типов вопросов, состояния `sel / correct / wrong`, разбор под вопросом.
8. **Score ring** — итог теста, кольцо + вердикт.

## Принципы наполнения

- Каждое правило = одна короткая мысль + пример + перевод.
- Сначала логика/картинка (таймлайн, ось), потом текст.
- Минимум терминов, максимум «когда так говорят».
- Один экран = одна идея.
