# server — бэкенд langlab (PocketBase)

Живёт внутри проекта: схема и хуки версионируются вместе с фронтом, деплой — тот же
`git pull`. Наружу PocketBase не смотрит — слушает `127.0.0.1:8090`, публикует его nginx
на том же домене, что и сайт:

| адрес | что |
|---|---|
| `https://langs.crs-projects.com/` | сам сайт (статика из репозитория) |
| `https://langs.crs-projects.com/api/` | REST API PocketBase |
| `https://langs.crs-projects.com/_/` | админка PocketBase |

Один домен на всё — значит без CORS и без второго сертификата.

## Что в базе (и чего в ней нет)

Контент — уроки, тесты, вопросы — лежит в `content/` в git. В базе только то, что
принадлежит человеку, и ссылки на контент по id:

| коллекция | смысл |
|---|---|
| `users` | аккаунт, вход по коду из письма (OTP), регистрация закрыта |
| `profiles` | уровень, цель, ответы опроса |
| `programs` | персональная программа = упорядоченный плейлист id уроков |
| `progress` | пройденные уроки |
| `test_results` | все попытки тестов (лучший балл считается по ним) |

Все коллекции закрыты правилом «вижу только своё». Суперюзер правила обходит —
поэтому программу под человека правлю руками в админке, не трогая JSON в файлах.

## Запуск

```bash
cd server && docker compose up -d --build
```

Схема применяется сама: файлы `pb_migrations/*.js` прогоняются при старте.
Данные — в `server/pb_data/` (в git не попадают).

## Первый запуск

PocketBase печатает в лог одноразовую ссылку на создание суперюзера:

```bash
docker compose logs pocketbase | grep pbinstal
```

Открыть её через домен (`https://langs.crs-projects.com/_/#/pbinstal/…`) и завести
себе админа. Пароль ставишь ты, в репозитории и у меня его нет.

Потом в админке: **Settings → Mail settings** — прописать SMTP, иначе коды на почту
не уйдут. Дальше **Collections → users → New record** — завести аккаунты себе и Карине.

## Бэкап

Вся база — один файл. Снять копию:

```bash
ssh root@95.182.97.209 'tar czf /root/backups/langlab-pb-$(date +%F).tar.gz -C /var/www/langs.crs-projects.com/server pb_data'
```

## Обновление PocketBase

Поднять `PB_VERSION` в `Dockerfile` и `docker-compose.yml`, закоммитить, на сервере
`git pull && docker compose up -d --build`. Версия прибита специально — чтобы выкат
не приносил незапланированный апгрейд.
