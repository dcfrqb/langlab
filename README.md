# langlab — платформа для изучения языков

> Рабочее имя (`langlab`) — временное, переименуем в любой момент.
> Извлечено 2026-08-15 из личного прототипа `~/Documents/Мир/Английский/Сайт`
> (тот остаётся жить и работать на `eng.crs-projects.com`).

Мультиязычная обучающая платформа: грамматика «как система, а не список правил»,
анимированные таймлайны, тесты, словарь. Выросла из личного сайта по английскому,
который понравился нескольким людям → делаем полноценную версию.

## Что это (и чем НЕ является пока)

- **Есть сейчас**: рабочий фронт на ванильном JS без сборки — плеер уроков, анимированные
  SVG-таймлайны, режим тестов (7 типов вопросов; в английском — 30 тестов и 826 вопросов),
  экраны результатов и готовности к экзамену.
  Движок, UI и контент разделены; светлая/тёмная тема, mobile-first. Прогресс — в localStorage.
- **Нет пока** (осознанно): бэкенда, БД, аккаунтов, второго/третьего языка. Это следующие фазы.

## Запуск (локально)

```bash
python3 -m http.server 8770
```

→ http://localhost:8770. Никакой сборки — чистый HTML/CSS/JS + ES-модули.
Открывать через сервер (не `file://`), иначе браузер не подгрузит модули.

## Структура

```
langlab/
  index.html           — точка входа (подключает ui/ и app/main.js)
  app/main.js          — загрузчик: выбирает курс и запускает движок
  engine/              — движок, ничего не знает про конкретный язык
    course.js            обёртка курса (цвета категорий, поиск уроков/тестов)
    router.js            hash-маршруты
    player.js            плеер урока
    quiz.js              движок тестов (7 типов вопросов)
    review.js            интервальные повторения: расписание по вопросу и ритм по дням
    rhythm.js            точки занятий за две недели
    steps.js             рендер шагов урока (включая шаг-упражнение)
    algorithm.js         клинический алгоритм: дерево решений по шагам и картой
    timeline.js          анимированные SVG-таймлайны
    explorer.js          интерактивная карта (для EN — карта времён)
    storage.js           данные пользователя (сегодня localStorage, завтра API)
    theme.js keys.js nav.js rail.js
    screens/             home · today · tests · terms · results · level
  ui/                  — дизайн-система
    tokens.css           цвета/шрифты/ритм, светлая и тёмная темы
    base.css components.css player.css tests.css
    DESIGN.md            описание системы
  content/             — курсы данными (это авторит Claude)
    en-ru/               английский: 33 темы, 826 вопросов, оценка уровня (свой README)
    medicine/            USMLE: карты учебников + алгоритмы (свой README)
    ielts/               IELTS Academic: приёмы чтения и письма (свой README)
  server/              — бэкенд: PocketBase (docker) + схема в pb_migrations/
  tools/               — оффлайн-инструменты: разбор PDF-учебников, проверка контента
                         (`node tools/en-ru/check.mjs`, `node tools/ielts/check.mjs`)
  README.md ROADMAP.md
```

Бэкенд — [PocketBase](server/README.md) внутри проекта: аккаунты (вход по коду из письма),
профиль, персональные программы, прогресс, результаты тестов. Контент в БД не копируется —
там только ссылки на его id. Фронт пишет в localStorage сразу, а в базу отправляет фоном
(`engine/sync.js`), поэтому работает и без сети, и до входа.

Как добавить курс: положить `content/<code>/` со своим манифестом (категории, уроки,
тесты, палитра) и внести его в реестр `COURSES` в `app/main.js`. Движок и `ui/` не трогаются.

**Доза дня** (`#/today`) — то, ради чего всё остальное. Движок держит расписание по каждому
вопросу (ступени 1 / 3 / 7 / 16 / 35 дней, промах роняет на две ступени вниз, а не в начало;
угаданное с первого раза стартует сразу с трёх дней, а не с завтра) и собирает несколько
вопросов на сегодня сам: сначала просроченные повторы, потом новое из зон, где чаще
промахивались. Часть дозы всегда забронирована под новое (`freshShare` в манифесте, у
английского 40%): без брони десяток пройденных подряд тестов забивает очередь повторами
на месяц вперёд, и каждый день выглядит как вчерашний. Размер дозы курс называет сам
(`dose`, у английского 12). Выбора на этом экране нет намеренно — «с чего начать» и есть
то трение, на котором ежедневность ломается. Ритм считается плотностью («11 дней из 14»),
а не серией подряд: пропуск убирает точку и ничего не обнуляет, а день засчитывается
с первого ответа. Из тех же записей сам собой считается журнал ошибок на «Результатах» —
раньше он вёлся руками в тетради.

Курс может включить себе разделы, которых у других нет, — движок смотрит на манифест,
а не на список курсов: словарь появляется, если в уроках есть шаги `terms` (и называется
так, как скажет `termsCopy`), опрос уровня — если не выключен `survey: false`,
экран «Готовность» (`#/level`) — если курс отдал функцию `estimate(stats)`,
доза дня — если у курса есть банк вопросов (а какие вопросы в неё не пускать, курс
говорит через `dailyFilter`: у английского это замер).
Как превращать баллы в уровень, знает курс, а не платформа.
Курс выбирается адресом (`?c=medicine`) и запоминается, а вошедшему открывается тот,
по которому ему назначена активная программа в базе.

## Деплой

Только через git — никаких выкладок мимо репозитория:

```bash
git push && ssh root@95.182.97.209 'git -C /var/www/langs.crs-projects.com pull -q'
```

Если менялось что-то в `server/` (схема, версия PocketBase) — после pull ещё и перезапуск,
иначе новые миграции не применятся. Нужен именно `restart`: `up -d` видит, что конфиг
compose не менялся, печатает «Container langlab-pb Running» и ничего не делает — файлы
миграций смонтированы томом и остаются лежать непрогнанными.

```bash
ssh root@95.182.97.209 'cd /var/www/langs.crs-projects.com/server && docker compose restart'
```

Живёт на <https://langs.crs-projects.com> (вебрут = клон этого репо,
nginx: `/etc/nginx/sites-available/langs.crs-projects.com`, сертификат Let's Encrypt,
`.git` наружу закрыт). Сборки нет, поэтому pull — это и есть выкат.

## Ключевой принцип

**Контент — в git (файлы, версионируется, авторит Claude). Данные пользователя — в БД**
(аккаунт, ответы опроса, уровень, персональная «программа» = плейлист поверх общего
контента, прогресс). Так «гибкая к редактированию программа под каждого» не превращается
в редактирование сырого JSON руками.
