# langlab — платформа для изучения языков

> Рабочее имя (`langlab`) — временное, переименуем в любой момент.
> Извлечено 2026-08-15 из личного прототипа `~/Documents/Мир/Английский/Сайт`
> (тот остаётся жить и работать на `eng.crs-projects.com`).

Мультиязычная обучающая платформа: грамматика «как система, а не список правил»,
анимированные таймлайны, тесты, словарь. Выросла из личного сайта по английскому,
который понравился нескольким людям → делаем полноценную версию.

## Что это (и чем НЕ является пока)

- **Есть сейчас**: рабочий фронт на ванильном JS без сборки — плеер уроков, анимированные
  SVG-таймлайны, режим тестов (7 типов вопросов, 13 тестов, 90 вопросов), экран результатов.
  Движок, UI и контент разделены; светлая/тёмная тема, mobile-first. Прогресс — в localStorage.
- **Нет пока** (осознанно): бэкенда, БД, аккаунтов, второго/третьего языка. Это следующие фазы.

## Запуск (локально)

```bash
python3 -m http.server 8770
```

→ http://localhost:8770. Никакой сборки — чистый HTML/CSS/JS + ES-модули.
Открывать через сервер (не `file://`), иначе браузер не подгрузит модули.

## Структура

```
langlab/
  index.html           — точка входа (подключает ui/ и app/main.js)
  app/main.js          — загрузчик: выбирает курс и запускает движок
  engine/              — движок, ничего не знает про конкретный язык
    course.js            обёртка курса (цвета категорий, поиск уроков/тестов)
    router.js            hash-маршруты
    player.js            плеер урока
    quiz.js              движок тестов (7 типов вопросов)
    steps.js             рендер шагов урока
    timeline.js          анимированные SVG-таймлайны
    explorer.js          интерактивная карта (для EN — карта времён)
    storage.js           данные пользователя (сегодня localStorage, завтра API)
    theme.js keys.js nav.js rail.js
    screens/             home · tests · results
  ui/                  — дизайн-система
    tokens.css           цвета/шрифты/ритм, светлая и тёмная темы
    base.css components.css player.css tests.css
    DESIGN.md            описание системы
  content/             — курсы данными (это авторит Claude)
    en-ru/               index.js (манифест) · lessons.js · tests.js · course.css
  README.md ROADMAP.md
```

Появится после выбора бэкенда: `server/` — API + БД (аккаунты, прогресс, программы).

Как добавить язык: положить `content/<code>/` со своим манифестом (категории, уроки,
тесты, палитра) и переключить импорт в `app/main.js`. Движок и `ui/` не трогаются.

## Деплой

Только через git: коммит → `git push` в [dcfrqb/langlab](https://github.com/dcfrqb/langlab)
→ `git pull` на сервере (`root@95.182.97.209`, сайт на `langs.crs-projects.com`).
Никаких выкладок мимо репозитория.

## Ключевой принцип

**Контент — в git (файлы, версионируется, авторит Claude). Данные пользователя — в БД**
(аккаунт, ответы опроса, уровень, персональная «программа» = плейлист поверх общего
контента, прогресс). Так «гибкая к редактированию программа под каждого» не превращается
в редактирование сырого JSON руками.
