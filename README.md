# langlab — платформа для изучения языков

> Рабочее имя (`langlab`) — временное, переименуем в любой момент.
> Извлечено 2026-08-15 из личного прототипа `~/Documents/Мир/Английский/Сайт`
> (тот остаётся жить и работать на `eng.crs-projects.com`).

Мультиязычная обучающая платформа: грамматика «как система, а не список правил»,
анимированные таймлайны, тесты, словарь. Выросла из личного сайта по английскому,
который понравился нескольким людям → делаем полноценную версию.

## Что это (и чем НЕ является пока)

- **Есть сейчас** (скопировано как стартовое ядро, папка `app/`): рабочий статический
  сайт-движок на ванильном JS — плеер уроков, анимированные SVG-таймлайны, режим тестов
  (7 типов вопросов, 13 тестов, 90 вопросов), экран результатов. Прогресс — в localStorage.
- **Нет пока** (осознанно): бэкенда, БД, аккаунтов, второго/третьего языка. Это следующие фазы.

## Запуск (локально)

```bash
cd app && python3 -m http.server 8770
# → http://localhost:8770
```

Никакой сборки — чистый HTML/CSS/JS. Открывать через сервер (не `file://`),
иначе браузер не подхватит соседние скрипты.

## Структура

```
langlab/
  app/                 — текущий сайт-движок (работает как есть)
    index.html
    scripts/  app.js (движок) · data.js (уроки EN) · tests.js (банк тестов)
    styles/   design.css (токены) · app.css (компоненты)
    DESIGN.md          — дизайн-система
  README.md            — этот файл
  ROADMAP.md           — решения, фазы, что дальше
```

Целевая структура (куда придём при рефакторинге, см. ROADMAP) — разделение
**движок / контент / UI / данные пользователя**:

```
  engine/    — рендер, роутер, движок тестов, SRS (без контента)
  ui/        — дизайн-система: токены + компоненты
  content/   — курсы данными: en-ru-a1/, de-ru-a1/, … (это делает Claude)
  app/       — загрузчик
  server/    — (после решения по бэкенду) API + БД: аккаунты, прогресс
```

## Ключевой принцип

**Контент — в git (файлы, версионируется, авторит Claude). Данные пользователя — в БД**
(аккаунт, ответы опроса, уровень, персональная «программа» = плейлист поверх общего
контента, прогресс). Так «гибкая к редактированию программа под каждого» не превращается
в редактирование сырого JSON руками.
