# ROADMAP — langlab

Зафиксировано из обсуждения 2026-08-15. Живой документ — правим по ходу.

## Видение

Из личного сайта по английскому → мультиязычная платформа. Триггер: минимум 3 человека
попросили доступ. Отличие от Duolingo и ко — **качество + персонализация** (примеры под
контекст и цель конкретного человека), а не ширина охвата.

## Решения (зафиксированы)

| Решение | Выбор | Почему |
|---|---|---|
| Где живёт | Отдельный git-репо в `CRS-Projects/` (этот) | Личный сайт остаётся в `Мир/`, ничего не мигрируем |
| Деплой | GitHub `dcfrqb/langlab` → `git pull` на сервере, домен `langs.crs-projects.com` | Всё через репозиторий, никаких выкладок мимо гита |
| Бэкенд | **PocketBase**, внутри репо (`server/`), docker на своём сервере | Аккаунты, права и админка из коробки; бэкап = один файл; программу под человека правим руками в админке. Supabase — тяжело для трёх юзеров, свой бэк — время на обвязку вместо сути |
| Судьба eng-сайта | **Заменить eng позже** | Строим параллельно; когда платформа перегонит — переводим `eng.crs-projects.com` на неё и гасим старый |
| Извлечение | **Копия**, не перенос | Оригинал в `Мир/Английский/Сайт` продолжает работать |
| Прогресс/уровень юзера | Живёт в localStorage браузера, не в файлах | Мигрировать нечего; старый сайт не трогается |
| Контент vs данные | Контент — в git (авторит Claude). Данные юзера — в БД | Гибкость программ без редактирования JSON руками |
| Первые языки | **EN + DE** (готов / начат), **FR позже** | FR с нуля — большой объём, не блокируем им старт |
| Вход | Склоняемся к **magic-link** (почта → ссылка → вход) | «Его персональная ссылка», но с аккаунтом и без паролей |
| Темы/мобилка | Свет + тьма и **mobile-first** — в костяк с первого дня | Сейчас сайт десктопный |

## Медицинский профиль (USMLE) — начат 2026-08-16

Третий пользователь, и первый не-языковой: подготовка по First Aid (Step 1 — база 1–3 курса,
Step 2 CK — клиника, Clinical Algorithms). Проверка того, что «langlab» — платформа под
человека, а не курсы английского: движок и `ui/` не трогаются, появляется свой контент.

Отличие от языковых курсов: главное — не уроки, а **алгоритмы** (дерево решений: «шок —
кожа тёплая или холодная») и **повторение** фактов, а не тесты «сдал и забыл».

| | Что | Статус |
|---|---|---|
| Конвейер | PDF → карта книги + поиск по страницам + валидатор контента | ✅ 2026-08-16 |
| Формат | алгоритм как дерево решений, ссылка на страницу учебника | ✅ 2026-08-16 |
| Движок | реестр курсов, курс `medicine`, шаг-алгоритм (по шагам / вся карта) | ✅ 2026-08-17 |
| Аккаунт | профиль и программа заведены миграцией `1786804000` | ✅ 2026-08-17 |
| Выжимки | шаг-таблица + ссылка на страницу учебника у любого шага | ✅ 2026-08-17 |
| Термины | шаг `terms` в теме + словарь курса с поиском (`#/terms`) | ✅ 2026-08-17 |
| Тесты | банк вопросов по пройденным темам + отдельный тест на термины | ✅ 2026-08-17 |
| Контент | 3 темы: брадиаритмии, шок, АДГ (32 термина, 32 вопроса) | 🟡 |
| Повторения | карточки из развилок алгоритма + интервальные повторения | ⬜ |

Что попросила она сама: выжимки по темам из Step 1 и Step 2 CK, английская терминология,
тесты по пройденному. Состав курса собран под это; тема «АДГ» показывает, как выглядит
«объединить учебники» — механизм из Step 1, тактика из Step 2 CK, у каждого шага
своя страница-источник.

Аккаунт под неё заведён миграцией, а не руками в админке: заведённое руками теряется
при переносе базы и нигде не записано. Почта — заглушка `medicine@langlab.local`
(писем мы не шлём, вход по персональной ссылке); настоящий адрес можно поставить
в админке, на вход это не влияет.

Учебники в git не едут (вес и права) — детали в [content/medicine/README.md](content/medicine/README.md).

## Правило приоритета

Не строить вширь (3 языка × все уроки), пока **вертикальный срез** (фаза 2: вход → урок →
сохранённый прогресс) не заработает насквозь. Один тонкий сквозной канал важнее горы контента без спины.
