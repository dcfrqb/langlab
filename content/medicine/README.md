# Медицина — контент и конвейер из учебников

Профиль под подготовку к USMLE: First Aid Step 1 (база 1–3 курса) и Step 2 CK
(клиника), плюс Clinical Algorithms. Термины — по-английски, как на экзамене;
объяснения и интерфейс — по-русски.

## Принцип

**Учебник — источник, а не контент.** PDF в git не едут: вес (одна книга — 93 МБ,
другая 320 МБ) и права. В репозитории живёт только то, что написано нами:
алгоритмы как деревья решений, карточки, разборы. У каждого — ссылка на страницу
книги, чтобы можно было пойти и свериться с оригиналом.

```
content/medicine/
  *.pdf              — сами учебники (gitignore: вес и права)
  books/*.js         — карты книг: оглавление и номера страниц (генерируются)
  algorithms/*.js    — деревья решений (пишем руками, глядя в книгу)
tools/medicine/
  extract.py         — PDF → карта книги + постраничная выжимка
  book.py            — поиск, чтение страниц, рендер схем (инструмент автора)
  check.mjs          — проверка контента перед коммитом
  out/               — выжимка с текстом книг (gitignore)
```

## Конвейер

Один раз поставить окружение:

```bash
python3 -m venv tools/.venv && tools/.venv/bin/pip install -r tools/requirements.txt
```

Новая книга приехала — разобрать:

```bash
tools/.venv/bin/python tools/medicine/extract.py "content/medicine/<файл>.pdf" --id fa-step1-2025 --short "First Aid Step 1" --year 2025
```

Даёт две вещи: `tools/medicine/out/<id>/pages.jsonl` — текст постранично (в git не едет,
нужен для поиска) и `content/medicine/books/<id>.js` — карту книги (едет в git; там только
оглавление и номера страниц, текста книги нет).

Дальше — писать контент, сверяясь с книгой:

```bash
tools/.venv/bin/python tools/medicine/book.py toc --grep bradyarrhythmia   # где это в книге
tools/.venv/bin/python tools/medicine/book.py find "warm dry skin"         # где встречается
tools/.venv/bin/python tools/medicine/book.py page 365 --to 366            # прочитать страницу
tools/.venv/bin/python tools/medicine/book.py image 365                    # посмотреть схему
```

Схемы-алгоритмы вытаскиваются из PDF как россыпь подписей без связей между ними —
дерево по тексту не восстановить, поэтому страницу со схемой нужно именно смотреть
(`image`), а связи переносить руками. Это не автоматизируется честно.

Перед коммитом:

```bash
node tools/medicine/check.mjs
```

## Печатный номер ≠ номер в файле

Печатная нумерация начинается после обложки и предисловия: в «Алгоритмах» сдвиг 23
(файловая 388 = печатная 365), в Step 1 — 21, в Step 2 CK — 17. В ссылках всегда печатный
номер, тот, что человек увидит в книге; файловый нужен только чтобы открыть PDF в нужном
месте, и лежит в карте книги.

**Меток может не быть.** У First Aid Step 1 2025 они выдраны — книгу прогоняли через
iLovePDF. Тогда `extract.py` снимает номер с колонтитула и доверяет не отдельной странице,
а самому частому сдвигу (у Step 1 он сошёлся на 842 страницах из 865): цифра из таблицы
у края страницы иначе увела бы всю нумерацию. Как получены номера, видно в карте книги —
поле `labels`: `pdf` или `headers`.

## Колонтитул точнее оглавления

В Step 1 всего 39 закладок на 844 страницы — раздел там это целая глава («Endocrine»,
90 страниц). Поэтому `book.py` называет тему по колонтитулу страницы, а не по оглавлению:
`First Aid Step 1 2025, стр. 342 · ENDOCRINE · endocrine—pathology`. Колонтитул лежит
выше 6.5% высоты страницы, текст начинается ниже 7.5% — по этой границе он и режется,
одинаково во всех трёх книгах.

## Алгоритм — формат

Дерево решений, а не картинка: движок ведёт по одной развилке за раз. Образец —
[algorithms/shock.js](algorithms/shock.js) (FA Clinical Algorithms, 10-3, стр. 365).

| поле | что | обязательно |
|---|---|---|
| `id` `title` `titleEn` `subject` | опознание и предмет (задаёт цвет) | да |
| `lede` | зачем этот алгоритм — одна фраза | нет |
| `source` | `{ book, section, page }` — проверяется `check.mjs` | да |
| `start` | id корневого узла | да |
| `notes` | сноски книги своими словами, узлы ссылаются по ключу | нет |
| `nodes[]` | узлы дерева | да |

Узел:

| поле | что |
|---|---|
| `kind` | `root` · `finding` (что видим) · `test` (что делаем, чтобы увидеть) · `dx` (диагноз) · `tx` (лечение) · `ref` (дальше по другому алгоритму) |
| `label` / `labelEn` | по-русски / термин как в книге |
| `ask` | вопрос развилки — обязателен, если веток больше одной |
| `why` | почему признак означает именно это (наше, не из книги) |
| `note` | ключ сноски |
| `next[]` | `{ to, label, labelEn }` — куда и по какому ответу |

Правила, которые держит `check.mjs`: id уникальны, все ссылки резолвятся, каждый узел
достижим от `start`, ветка кончается только на `dx`, `tx` или `ref`, страница источника
попадает в диапазон своего раздела. По урокам он же проверяет: предмет и группа объявлены
в курсе, в строках таблиц столько ячеек, сколько столбцов, у термина есть перевод,
у каждого теста в пуле есть вопросы.

## Что в курсе, кроме алгоритмов

Просьбы, под которые сделан состав курса: выжимки по темам из Step 1 и Step 2 CK,
английская терминология, тесты по пройденному.

| тип шага | что это | пример |
|---|---|---|
| `concept` `note` | мысль темы и акценты | «один гормон, две крайности» |
| `table` | сравнение в столбцах — основная форма First Aid | polydipsia / central DI / nephrogenic DI |
| `terms` | термины темы: EN главное, RU и подсказка под ним | `euvolemic hyponatremia` |
| `algorithm` | дерево решений | «шок: кожа тёплая или холодная» |
| `quiz` | проверка внутри темы | — |

У любого шага может быть `src: { book, page }` — печатный номер страницы учебника.
Выжимке надо верить, а для этого её должно быть можно перепроверить за десять секунд;
`check.mjs` следит, что такая страница в книге есть.

**Терминология** нигде не дублируется: словарь на `#/terms` собирается из шагов
`type:'terms'` (`course.terms`), поэтому список и уроки не могут разъехаться.
Поиск идёт и по английскому, и по русскому.

**Тесты** используют общий движок языкового курса — типы вопросов те же
(`choose`, `pick`, `gap`, `mgap`). Банк — `tests.js`, рубеж на тему плюс отдельный
тест на термины. Правило: спрашиваем только то, что есть в пройденных темах.

## Как это показывается

Алгоритм — это шаг урока (`{ type: 'algorithm', algorithm }`), а не отдельный экран:
так он получает даром прогресс, программу и синхронизацию с базой. Рендерит его
`engine/algorithm.js` в двух режимах — «по шагам» (один вопрос за раз, как у постели
больного) и «вся карта» (то же дерево целиком, как разворот в книге).

Виды узлов различаются весом и рамкой, а не своим цветом: на экране один акцент —
цвет темы. Картинку страницы из PDF не показываем: на телефоне схема нечитаема,
а живое дерево читается.

## Что дальше (ещё не сделано)

- Карточки на повторение: развилка алгоритма — это готовая карточка
  («кожа тёплая и сухая → какая группа шока?»), поэтому генерируются из дерева, а не
  пишутся второй раз. Руками — только факты, которые не алгоритмы (fast facts из Step 1).
- Интервальные повторения: для First Aid это главный режим, важнее тестов.
- Оглавление Step 1 по темам: в PDF закладок только на главы, но колонтитулы дают
  тему на каждой странице — из них можно собрать полноценное дерево разделов.
- PDF рядом с контентом на сервере: книги нельзя выкладывать через git, значит копировать
  на сервер отдельно и закрывать доступ логином.
